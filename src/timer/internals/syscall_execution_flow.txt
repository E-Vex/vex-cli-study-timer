===================================================================
->      Syscall Execution Flow (User Space vs Kernel Space)      <-
===================================================================


USER SPACE (Your Program)                   KERNEL SPACE (Operating System)
─────────────────────────                   ───────────────────────────────

RAX=35  ─┐
RDI=ptr ─┤  (pointer to request)
RSI=ptr ─┤  (pointer to remaining)
         │
┌────────▼────────┐
│     syscall     │   CPU jumps
│(CPU instruction)│ ────────────────►   Kernel takes control
└─────────────────┘                     
                                        ┌─────────────────────────┐
                                        │ 1. Checks RAX = 35      │
                                        │   -> This is nanosleep  │
                                        │                         │
                                        │ 2. Reads RDI            │
                                        │   -> Fetches tv_sec and │
                                        │    tv_nsec from request │
                                        │                         │
                                        │ 3. Saves RSI            │
                                        │   -> Uses it to store   │
                                        │    unslept time if the  │
                                        │    sleep is interrupted │
                                        │                         │
                                        │ 4. Puts the program to  │
                                        │    sleep for the        │
                                        │    requested duration   │
                                        └───────────┬─────────────┘
                                                    │
                           (After time expires)     │
                                                    │
┌──────────────────────┐                            │
│ Control returns to   │ ◄──────────────────────────┘
│ the line right after │
│ the "syscall"        │
│ RAX = 0 on success   │
│ RAX = -EINTR if      │
│ interrupted          │
└──────────────────────┘


===================================================================
->              Related syscall: clock_gettime                  <-
===================================================================

The countdown also calls clock_gettime directly:

  RAX = 228               ← syscall number (clock_gettime)
  RDI = 1                 ← CLOCK_MONOTONIC
  RSI = &timespec         ← receives seconds + nanoseconds

CLOCK_MONOTONIC cannot jump backwards when the wall clock is adjusted, which
makes it suitable for measuring elapsed time. The timer stores an absolute
deadline and compares it with this clock on every display tick.
